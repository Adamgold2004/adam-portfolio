# Adam Studio portfolio

Custom WordPress theme for Adam Studio, with portfolio, services, team, contact,
and project inquiry pages.

## Deploy to Render

[Deploy to Render](https://render.com/deploy?repo=https://github.com/Adamgold2004/adam-portfolio)

The Blueprint provisions a WordPress web service and a private MySQL database
with persistent storage. **These are paid resources**: review the Render cost
estimate before creating them. Supply your WordPress administrator email when
prompted; Render generates the initial administrator password.

See [DEPLOYMENT.md](DEPLOYMENT.md) for configuration, administrator access,
persistence, validation status and content migration notes.

The source theme is in `designs-ng-theme/`. The local test installation and its
shared database are excluded. Deployment creates the theme's bundled content.
